# 🚀 Nexa Chain

A modern full-stack web application built with a **Node.js/Express backend** and a **Vite-powered frontend**.

## 📦 Tech Stack

### Backend
- Node.js
- Express.js
- REST API

### Frontend
- Vite
- JavaScript
- Modern UI

---

# ⚡ Getting Started

## 1. Clone the Repository

```bash
git clone https://github.com/pkjmap/nexa-chain.git
cd nexa-chain
```

---

## 2. Install Dependencies

### Backend

```bash
cd backend
npm install
```

### Frontend

```bash
cd ../frontend
npm install
```

---

## 3. Start the Backend Server

```bash
cd ../backend
npm run start
```

The backend server will start at:

```
http://localhost:5000
```

---

## 4. Start the Frontend

Open a new terminal and run:

```bash
cd frontend
npm run dev
```

The frontend will be available at:

```
http://localhost:5173
```
